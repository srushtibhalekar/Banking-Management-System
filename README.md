# Banking Management System

A console-based Banking Management System developed using Core Java, JDBC, and PostgreSQL.

## Features

- Create bank account
- View all accounts
- Deposit money
- Withdraw money
- Delete account
- PostgreSQL database integration
- Exception handling
- OOP-based architecture

## Technologies

- Java
- Core Java
- OOP
- JDBC
- PostgreSQL
- VS Code

## How to Run

1. Install JDK 25
2. Install PostgreSQL
3. Create `banking_db` database
4. Configure database credentials
5. Add PostgreSQL JDBC driver
6. Compile and run `Main.java`
